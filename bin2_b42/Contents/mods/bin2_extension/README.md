# bin2 的扩展模组

- [x] 配方 简易木钳 拆分 为2个木棒和1碎布条
- [x] 制盐配方: 任意锅具 (平底煮锅/铜煮锅/炖锅/锻造炖锅/水壶/铜水壶) + 0.5 升水 + 1 木炭 → 1 盐,锅具保留
- [x] 熬制胶水: 2 骨头 + 1 锅具 + 1 升水 → 2 胶水 (原版 9 条配方要胶水,却只能采集)
- [x] 制作螺母螺栓: 1 木炭 + 1 金属料 + 锤子 + 钳子/火钳 → 6 螺母螺栓 (原版 33 条配方要它,却只能拆家具)
- [x] 制作螺丝: 1 木炭 + 1 金属料 + 锤子 + 钳子/火钳 → 6 螺丝 (原版只能开箱得到)
- [x] 制作圆锯片: 2 木炭 + 1 金属板 + 锤子 + 凿子 + 钳子/火钳 → 1 圆锯片 (原版 11 条配方要它)
- [x] 制作手锯条: 1 木炭 + 1 小金属板 + 锤子 + 凿子 → 2 手锯条

## 缺口是怎么找出来的

`bin2_b42/tools/recipe_gap/scan_recipe_gaps.py` 扫描游戏自带脚本,统计每个物品
"被哪些配方当**材料**消耗"(工具位 `Prop1/Prop2/ToolLeft/ToolRight` 不算)以及
"能被什么产出"(craftRecipe 输出 + itemMapper 映射值 + evolvedrecipe 结果 + 拆家具/采集)。
两边都不沾的物品就是只能搜刮的材料。Build 42.21 的结论见 `docs/craft-recipe-study.md` 第 14 节。
