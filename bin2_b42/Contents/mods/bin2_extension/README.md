# bin2 的扩展模组

- [x] 配方 简易木钳 拆分 为2个木棒和1碎布条
- [x] 制盐配方: 任意锅具 (平底煮锅/铜平底煮锅/蒸煮锅/粗制蒸煮锅/水壶/铜制水壶) + 0.5 升水 + 1 木炭 → 1 盐,锅具保留
  (物品中文名一律照游戏 `ItemName.json`,别自己起名 —— `Base.Pot` 是**蒸煮锅**,不是"炖锅")
- [x] 熬制胶水: 2 骨头 + 1 锅具 + 1 升水 → 2 胶水 (原版 9 条配方要胶水,却只能采集)
- [x] 制作螺母螺栓: 1 木炭 + 1 金属料 + 锤子 + 金属加工钳或夹钳 → 6 螺母螺栓 (原版 33 条配方要它,却只能拆家具)
- [x] 制作螺丝: 1 木炭 + 1 金属料 + 锤子 + 金属加工钳或夹钳 → 6 螺丝 (原版只能开箱得到)
- [x] 制作圆锯片: 2 木炭 + 1 金属板 + 锤子 + 金属加工凿 + 金属加工钳或夹钳 → 1 圆锯片 (原版 11 条配方要它)
- [x] 制作手锯条: 1 木炭 + 1 小金属板 + 锤子 + 金属加工凿 → 2 手锯条
- [x] 锻造耙头: 4 个 1/4 铁条 + 5 木炭 + 铁匠锤 + 夹钳 + 金属加工冲头 → 1 耙头 (锻造 7 级,任意锻造炉;
  **冲头 `Base.MetalworkingPunch` ≠ 凿 `Base.MetalworkingChisel`** —— 圆锯片/手锯条要的是凿,耙头要的是冲头;
  原版锻造配方覆盖锄头/铁铲/丁字镐/镰刀/各种斧头与锤头,唯独没有耙头 —— 耙头只能搜刮或拆整把耙子;
  设计理由与回炉算式见 `docs/craft-recipe-study.md` 14.13)

## 缺口是怎么找出来的

`bin2_b42/tools/recipe_gap/scan_recipe_gaps.py` 扫描游戏自带脚本,统计每个物品
"被哪些配方当**材料**消耗"(工具位 `Prop1/Prop2/ToolLeft/ToolRight` 不算)以及
"能被什么产出"(craftRecipe 输出 + itemMapper 映射值 + evolvedrecipe 结果 + 拆家具/采集)。
两边都不沾的物品就是只能搜刮的材料。Build 42.21 的结论见 `docs/craft-recipe-study.md` 第 14 节。
