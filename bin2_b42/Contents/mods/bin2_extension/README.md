## 缺口是怎么找出来的

`bin2_b42/tools/recipe_gap/scan_recipe_gaps.py` 扫描游戏自带脚本,统计每个物品
"被哪些配方当**材料**消耗"(工具位 `Prop1/Prop2/ToolLeft/ToolRight` 不算)以及
"能被什么产出"(craftRecipe 输出 + itemMapper 映射值 + evolvedrecipe 结果 + 拆家具/采集)。
两边都不沾的物品就是只能搜刮的材料。Build 42.21 的结论见 `docs/craft-recipe-study.md` 第 14 节。

## 名字的来源（1.7.2 起）

**本模组只翻译配方名**（`Translate/CN/Recipes.json`），**不再自带 `ItemName.json`**。
理由：翻译表是"原版先加载、mod 后加载、同键后到覆盖先到"，所以模组里任何一条物品名都会盖掉上游的；
这份文件里 22 条是重复原版译名（其中 `Base.Pot`「陶锅」、`Base.CrudeWoodenTongs`「简易木钳」两条还是旧的），
3 条与依赖模组 `ZVirusVaccine42BETA` 自带的中文名相同。删掉之后物品名一律来自上游，写配方文案时照
`ItemName.json` 查真实名字（别按印象写：`Base.MetalworkingPunch` 是**金属加工冲头**、`Base.MetalworkingChisel` 是**金属加工凿**）。
