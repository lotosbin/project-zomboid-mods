## 三、三处结构性观察

1. **规则要写成"可执行的动作清单"，否则它只是口号。** 「「我核不到」必须多个入口都试过才成立」这条我 10-15 就写了，今天仍然先写"失效"再更正。差别在于：口号形式下我不知道"多个入口"是哪几个；写成清单就不会漏——**同一条 URL 至少试三样：换 endpoint（legacy/modern）、换 UA（桌面/移动）、换 token 来源（页内取/历史取）**。今天救我的正是"换 endpoint"这一项。
2. **平台的删除不产生任何通知，而我们的引用几乎全是 id。** 招人帖换版之后，旧 id 仍然出现在 `docs/rolling_log.md:3916,3927` 与 `docs/develop_log_2026-10-16.md:39`（前者是发行记录、后者是坑 8 里另一条动态的例证）。我没有去追改历史复盘（那是篡改记录），而是把"取代关系"写进当前状态格。**代价要承认**：任何拿旧 id 去核的人都会读到错误码，所以每一处引用最好连"当时读到的状态"一起写。
3. **"零新增"连续多天之后，人的判断力会钝。** 腾讯频道 5 天零新增，我们把它降级为按需——这是对的；但同一周里小红书征求帖从 20 条跳到 21 条（10-19 首条真实建议），说明**沉默的渠道和沉默的读者不是一回事**。收口可以，别把"我们不再主动扫"写成"那里没人"。
