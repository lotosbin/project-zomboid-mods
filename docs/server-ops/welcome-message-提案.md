# 欢迎语替换提案（新玩家进服第一眼看到的那段话）

**状态：提案，未上线。** 要动线上配置必须：① 需求方点头；② 先在渠道 Thread 报备一次
（我答应过渠道"改线上配置之前先跟他们说一句"）。

背景：三个渠道 **2026-10-16 22:00** 开始发招人文案。之后进服的人，**第一眼看到的就是这段欢迎语**，
而它现在的内容是几个老玩家的聊天记录。

## 现状（2026-10-15 RCON 直读，`<LINE>` 是换行）

```
呼噜发现：用烤箱烹饪需要将食物脱出烤箱才能看见烹饪进度<LINE>鸭鸭将《遗书》模组恢复改成了100%且活且珍惜<LINE>小熊说Hi<LINE>亮亮说酷<LINE>多宝说Hello<LINE>语音频道:https://kook.vip/tcLNlO<LINE>Q群:166309803<LINE>
```

**它做对的事**（别丢）：给了进群路径（KOOK ＋ Q群），而且第一条"烤箱"其实是一条**真有用的游戏提示**。

**它对新玩家失效的地方**：

1. **读起来像别人的聊天**——"某某说Hi / 某某说酷"对陌生人是纯噪音，看不出跟自己有什么关系。
2. **一个字都没说"第一次来该干什么"**：没有进服引导、没有"有问题问谁"、没有"这是什么服"。
3. **里面有五个老玩家的名字**，而渠道那侧的口径是**"公开文案不点名字"**。
   在服内点名不算对外发布，但同一份精神：**名字对陌生人是障碍，不是信息**。
4. 没有任何"这台服是长期的、别把它当一次性局"的提示 —— 而这正是它对外招人时唯一的卖点
   （线上公开名就叫「长期生存挑战」）。

## 拟稿（建议）

```
欢迎来到《呼噜小世界4》长期生存档
这里是长期档：世界不重置，请当成要住很久的地方来玩
第一次来：进 Q 群说一声，有人在会带你认路
语音频道:https://kook.vip/tcLNlO
Q群:166309803
小提示：用烤箱烹饪要把食物拿出来才能看见进度
```

**每一句的依据与风险（请按这一列判断，不要只看句子好不好听）**：

| 句子 | 依据 | 风险 / 需要你确认 |
| --- | --- | --- |
| "长期生存档 / 世界不重置" | 与线上公开名「长期生存挑战」一致 | **是对未来的承诺**。若你以后打算开新档，这句要一起改。请你确认这句可以写 |
| "请当成要住很久的地方来玩" | 是**期望**不是规则 | 无技术含义，属语气 |
| "进 Q 群说一声，有人在会带你认路" | Q群真实存在（欢迎语本来就有） | "有人在"是**会过期的状态**。若你不喜欢，改成"有问题进群问"更稳 |
| KOOK ＋ Q群 | 服务器自己给玩家的路径，逐字沿用 | 渠道已定"对外不写 KOOK"（两条短链指向不同）。**这是服内路径、不是对外文案**，我倾向保留；你若要统一口径就说 |
| 烤箱提示 | 原有内容里最有价值的一条，逐字保留 | 无 |
| （已删）"鸭鸭/小熊/亮亮/多宝…" | —— | **删的是名字，不是这段历史**。老玩家的痕迹建议移到 Q 群公告或群文件，而不是丢掉 |
| （**刻意不写**）PVE / PvP | —— | 线上 `PVP=true` 而名字写 PVE，**这件事还没定** ⇒ 欢迎语里**两边都不说**，等你的答复 |

**刻意不写的东西，和写上去的一样重要**：人数、倍率、福利、开服时长、"不会被拆家"这类保证，
一律不写 —— 它们都会过期，而这段话是每个新玩家都要看的。

## 怎么应用（三种，成本差很多）

1. **`changeoption`**（RCON，无需重启）—— 命令表里有这条"修改服务器设置"。**最省事，但我没验证过**，
   验证它必须真的发一条写命令（见 `docs/server-ops/README.md` §2 的只读边界）。
2. **改 ini 后 `reloadoptions`**（RCON 命令表里也有："重新加载服务器上的选项并同步至客户端"）——
   同样是**未验证**的路。
3. **改 ini 后重启** —— 确定可行，但会踢人；**现在服务器 0 人，此刻是重启成本最低的时段**。

我倾向：**先试 1，不行再试 2，都不行才谈 3**。但**任何一条都需要你先说"可以"**。
