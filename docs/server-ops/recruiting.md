## 5. 各渠道可以怎么切（要点，风格各自定）

- **小红书**：切「新手友好」——长期不删档、有人带、中文模组包齐。配图优先用游戏内实拍。
- **哔哩哔哩**：切「内容量」——165 个模组里能展开讲的东西很多（电力/能源路由/交易站/同伴狗），

- **QQ 群**：切「现在就有人」——短、带 IP 和端口、置顶。

**红线（这几类话现在不能说，因为没有证据）：**

- 具体在线人数、同时在线峰值、"服里现在有多少人"。
- 服务器规则、白名单、是否需要申请、封禁政策。
- 开服时长、上次开服时间、有无定期重置。
- 任何活动、奖励、福利、限时内容。
- 沙盒难度参数（僵尸倍率、经验倍率等）。
