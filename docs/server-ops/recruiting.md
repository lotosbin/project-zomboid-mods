## 7. 复核方式

```bash
scripts/check_server_online.sh     # 服务器还在不在 Steam 登记里（免凭据）
```

⚠ **这个脚本会骗人，别拿它单独当结论**（2026-10-16 晚实测两种坏法都遇到过）：
它一次 **1 秒就返回正常**，另一次 **挂住 90 秒以上没结束**；更早还出现过本机 DNS 把 Steam 域
解析到 `198.18.x.x`（本机代理的假 IP）而报"没登记"的假阴性。
⇒ 要么给它设上限（`python3 -c "import subprocess;subprocess.run(['bash','scripts/check_server_online.sh'],timeout=40)"`），
要么直接打 API（**不经过那个脚本**）：

```bash
curl -sS --max-time 15 "https://api.steampowered.com/ISteamApps/GetServersAtAddress/v1/?addr=110.42.14.5" \
  | python3 -c "import json,sys;d=json.load(sys.stdin)['response'];print(d['success'],[s['gameport'] for s in d.get('servers',[])])"
```

**判断"服务器在不在"最少要两条互不依赖的证据**（例如：Steam 登记 ＋ RCON 应答），
因为这条通路上的每一样东西（脚本、DNS、代理、本机负载）**今晚都单独出过故障**。

要线上实时值（模组数、人数、选项），走 RCON：`110.42.14.5:21523`，
凭据在本机 `~/Zomboid/Server/呼噜世界41.ini`。**读 `showoptions` 时注意长行会跨包分片，
必须把各包 payload 直接拼接**，否则会把 `Mods`/`WorkshopItems` 数成 134/71 这种假数字
（我第一次就踩了）。**凭据不入库、不进 Team 消息。**
