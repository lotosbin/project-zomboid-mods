title=Project A-Life: Start With NPC [Jimmy add-on] - 开局自带友方 NPC (Build 42)
description=新角色开局身边就有友方 NPC。默认它会跟着你走；也可以切换成 Jeem Extension 的「居民」，让它去守你的营地。
description=
description=依赖（缺一不可）：
description=  * Project A-Life [ALIFE NPCS]  (3803984183)
description=  * Project A-Life - Jeem Extension  (3806944055)   ← 只有「居民」模式需要，普通同伴模式只需 A-Life
description=
description=安装：订阅上面两个模组 + 本模组，在 Mods 里全部启用，开新档即可。
description=
description=开局同盟：生成的 NPC 所属阵营的声望会被立刻拉到 Jeem 声望阶梯的最高档「同盟（ALLIED）」，
description=因此它绝不会对你翻脸，也能被 Jeem 的居民系统直接收编（联机非管理员同样有效）。
description=注意：Jeem 声望按阵营记录，所以变成同盟的是整个阵营；可在沙盒里用 ALifeStartWithNPC.MakeAllied 关闭。
description=
description=两种模式（沙盒选项 ALifeStartWithNPC.Mode）：
description=  1) 同伴（默认）—— 生成一名友好 A-Life NPC，用 A-Life 原生的 follow 指令让它跟着你。
description=     优点：不需要基地、不占 Jeem 的基地名额、没有副作用。
description=  2) 居民 —— 交给 Jeem Extension 的居民系统：它会获得营地岗位、任务、作息与声望关系。
description=     注意：居民是守基地的，不会跟着你跑；若你还没有基地，会在出生点周围自动建一个小营地
description=     （占一个 Jeem 基地名额，可用 ALifeStartWithNPC.Resident_CreateCamp 关掉）。
description=
description=其它选项：是否开局同盟、数量 1~5、生成距离 1~6 格、指定阵营 id / 档案 id（留空自动挑友好阵营）、
description=死亡重生是否再发、详细日志。
description=
description=生效标志（Zomboid/console.txt，DebugLog 打开时）：
description=  [ALifeStartWithNPC] Bootstrap loaded (v0.1.0)
description=  [ALifeStartWithNPC] spawned <uid> at <x,y> (faction=... profile=...)
description=  [ALifeStartWithNPC] grant complete: 1/1 npcs (mode=1)
description=
description=重要说明（诚实声明）：
description=  * 本模组尚未在游戏中运行过验证（只做了源码级核对 + Lua 语法校验）。请把它当作 0.1.0 试验版。
description=  * 与其它 NPC 模组（Bandits2 等）共存未测试。A-Life 官方对 Bandits2 的判定是 unsupported。
description=  * 只创建 NPC，不修改 A-Life / Jeem 的任何文件；卸载后残留的 NPC 会按 A-Life 自己的规则回收。
description=
description=待办 / 已知限制：
description=  * 朝向固定为南（A-Life 的 createZombieShell 硬编码 IsoDirections.S）
description=  * 多人下非管理员玩家可能无法转居民（会被声望门槛拦住），此时自动降级为跟随同伴
description=  * 暂无 UI 提示，只有控制台日志
