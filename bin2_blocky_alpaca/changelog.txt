版本 0.1.0 (2026-10-03)
- 初始发布：4 种方块羊驼毛色（奶油 / 棕 / 灰 / 花斑），方块造型由脚本生成（23 个长方体、硬绑到 base 骨架）
- 与写实羊驼同物种：共用驮载/牧群/草食/怕热数值、共用叫声、可以互相繁殖
- 生成倍率跟随 CD: Alpacas 的沙盒选项（AlpacaSpawnMultiplier）
- 已知限制：未在游戏内实测（只做了离线渲染与 Lua 契约测试）；只提供 EN/CN/CH；绑骨是刚性绑定，
  所以没有任何软蒙皮形变（这是刻意的方块观感）
- 技术要点（踩过的两个坑，写在 models_blocky.txt 与 README 里）：每条剪辑对每根骨头都有位移轨道，
  改静止位移必须同步改剪辑通道，否则一播动画方块就散架；独立"蹄盒"绑脚骨会在 gallop 拉伸时飞出去，
  改成"腿的最下一段直接用蹄色"。
