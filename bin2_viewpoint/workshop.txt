title=ViewpointMac - 3D on macOS / Apple Silicon (experimental)
description=[h1]ViewpointMac —— macOS 上的 3D 视角（实验性）[/h1]
description=在 macOS / Apple Silicon 上把自研的 3D 渲染塞进 Project Zomboid 的帧里：先证明"能画"，
description=再一路做到第一人称自由视角 + 真 3D 物件（v2.2.0，Build 42.21）。
description=
description=[h2]它现在能做什么[/h2]
description=[list]
description=[*][b]渲染钩子[/b]：ZombieBuddy 在 zombie.core.SpriteRenderer#postRender 挂 OnEnter/OnExit，[b]从不跳过原版渲染[/b]
description=[*][b]GL 能力探针[/b]：在渲染线程读取 GL 版本 / 渲染器 / 扩展与硬件上限，并就地编译测试着色器，
description=  报告写到 [b]~/Zomboid/viewpointmac-report.txt[/b]
description=[*][b]第一 / 第三人称相机[/b]：自实现透视 / lookAt 矩阵，眼高、FOV、俯仰、跟随距离都可配
description=[*][b]3D 场景[/b]：GLSL 1.20 + MVP uniform + 深度缓冲 + 流式 VBO；地面网格、坐标轴、
description=  玩家线框盒、世界原点标记
description=[*][b]真 3D 物件[/b]：接入 PZ Voxel Studio 模型包（工坊 3810302175 / 3810051489），
description=  16 个包 / 9,187 个模型 / 10,110 条 bind 全部解析校验通过；命中 bind 的物件直接画模型
description=[*][b]地面与天空[/b]：地板铺面并贴原版地板精灵；程序化渐变天空盒
description=[*][b]全套自检与熔断[/b]：兼容性反射自检失败只禁用对应功能；渲染钩子连续异常 3 次永久关闭并写报告
description=[/list]
description=
description=[h2]唯一的快捷键[/h2]
description=[b]Ctrl + Alt + D[/b] —— 打开 / 关闭调试控制面板，所有开关都在面板里。
description=（不用 F9~F12：macOS 默认把它们当媒体键，游戏收不到。）
description=
description=[h2]依赖[/h2]
description=[list]
description=[*][b]ZombieBuddy[/b] 2.3.0 或更高（Java agent，必须在启动项里生效）
description=[*]想看真正的 3D 物件还需要第三方模型包 [b]PZ Voxel Studio[/b]（工坊 3810302175 / 3810051489）；
description=  没有它也能跑，只是物件只有盒子/地面
description=[*]仅 [b]macOS / Apple Silicon[/b]（实验目标平台）
description=[/list]
description=
description=[h2]安装[/h2]
description=[list]
description=[*]确认 ZombieBuddy.jar 已放在 Project Zomboid.app/Contents/Java/
description=[*]Steam → Project Zomboid → 属性 → 启动选项：
description=  -javaagent:ZombieBuddy.jar -Xmx6g -Xms2g --   （末尾的 -- 不能省）
description=[*]启动游戏 → 模组管理 → 勾选 ViewpointMac（ZombieBuddy 必须同时启用）
description=[*]首次加载 Java 模组时 ZombieBuddy 会弹窗要求授权，点 Yes（会核对 JAR 的 SHA-256）
description=[*]进游戏后左上角出现带边框的面板；Ctrl+Alt+D 打开调试面板；报告在 ~/Zomboid/viewpointmac-report.txt
description=[/list]
description=
description=[h2]配置[/h2]
description=首次运行自动生成 [b]~/Zomboid/viewpointmac.properties[/b]，可改覆盖层、相机 FOV / 眼高 /
description=跟随距离、地面网格半径、体素距离衰减、模型加载预算等；改完重启游戏生效。
description=
description=[h2]诚实说明（已知限制）[/h2]
description=[list]
description=[*]实验性工程，不是成品 3D 模组：目标是验证平台能力与管线，而非替代 Project Viewpoint
description=[*]原版世界物件是 [b]2D 等距精灵[/b]、没有 3D 几何，物件外形完全依赖第三方模型包
description=[*]模型逐个 draw call，还没做同模型实例合批；密集区靠绘制上限兜底
description=[*]天空目前是程序化渐变，还未换成原版云层贴图
description=[*]改了 Java 必须[b]重启游戏[/b]（Lua 会热重载、已加载的 class 不会），启动时会做版本握手
description=[/list]
